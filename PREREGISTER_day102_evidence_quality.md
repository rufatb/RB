## Fixed engineering contract

- New DeepSeek requests use `day102-grounded-v1`: explicit remaining-session
  horizon through 15:59 ET, dated Python technical facts with units and signs,
  and stable references to supplied public evidence. Previous-session context
  is not current opening-path data. After-close diagnostics cannot be morning
  predictions. Model setting, request budgets and no-retry policy stay fixed.
- Keep the archived four-field assessment parser. New model responses require
  evidence references and the requested horizon; canonical display rationales
  are generated from verified references and Python facts. Original provider
  prose is retained only in private bounded audit receipts. Prohibited technical
  assertions, unsupported references and malformed rows produce explicit
  per-symbol failures; independent valid siblings survive. This validates a
  finite contract, not general natural-language truth or predictive efficacy.
  A directional opinion citing only explicit investment commentary or a
  multi-year title is excluded as lacking intraday event support; a cited
  NO_EDGE assessment remains valid. Unclassified evidence is not thereby
  declared material or novel. Syntax/identity failures invalidate the response
  envelope; bounded per-symbol semantic failures preserve valid siblings.
- Deduplicate public headlines by canonical URL and normalized title before
  the existing eight-item cap. Label explicit commentary and multi-year title
  horizons; leave issuer role, novelty and first-disclosure date unknown unless
  established by evidence. Ticker-channel linkage is not materiality proof.
  Do not invent SEC events, primary-source verification or event timing.
- Preserve dated macro levels. Add changes only against an identified actual
  daily-bar reference with provider timestamps and a named comparison window.
  Never substitute range-start `chartPreviousClose` for a prior-session close,
  infer trend from a level, or call an observed daily reference a live quote.
  Missing change evidence must not erase independently valid levels.
- Pure text/HTML/concise-email views consume one Digest. Grounding failures,
  original coverage denominators and source/provenance receipts remain visible.
  No new acquisition or LLM work enters the 09:46/report/rendering path.
